## To the Shopmonkey Migration Team

Hello Shopmonkey Onboarding & Migration Team!

This package contains data extracted and transformed from legacy shop management software using [Lucerne](https://github.com/alecdromano/lucerne) — an automated data migration, transformation, and archival engine developed for automotive repair facilities.

### What is Lucerne?
Lucerne automates the extraction, normalization, reconciliation, and validation of legacy shop records (customers, vehicles, inventory, past invoices/work orders, payments, and individual line items). Rather than requiring manual re-entry or raw table dumps, Lucerne cleans and structures the dataset directly against **Shopmonkey's ETL import schemas**, ensuring:
- Deduplication and synthetic key resolution with clean fallback IDs (e.g., matching customers across phone/email/addresses).
- NHTSA vPIC-assisted vehicle decoding and normalization (year, make, model, sub-model, engine, drivetrain, VIN resolution).
- Line item categorization (labor vs. parts vs. fees vs. sublet) with historical pricing, costs, technician notes, and inventory cross-references.
- Exact column formatting matching Shopmonkey's official import templates.

You can inspect the open-source pipeline, schema definitions, and transformation logic at:  
👉 **[https://github.com/alecdromano/lucerne](https://github.com/alecdromano/lucerne)**

## File Specifications (`processed/`)

All files in `processed/` are formatted to directly map to the Shopmonkey ETL load phase:

1. **`customers.xlsx`**
   - **Target**: Shopmonkey Customers Import
   - **Key Fields**: `First Name*`, `Last Name*`, `Company Name (optional)`, `Primary Phone (optional)`, `Additional Phones (optional)`, `Primary Email (optional)`, `Address 1 (optional)`, `City (optional)`, `State (optional)`, `Zip Code (optional)`, `Lucerne ID`, `TSS ID`.
   - **Notes**: Includes Lucerne deterministic IDs to maintain referential integrity with vehicle ownership and past repair orders.

2. **`vehicles.xlsx`**
   - **Target**: Shopmonkey Vehicles Import
   - **Key Fields**: `Year*`, `Make*`, `Model*`, `Sub-Model (optional)`, `Engine Size (optional)`, `VIN (optional)`, `License Plate (optional)`, `Color (optional)`, `Mileage (optional)`, `Type`, `Owners (optional)`, `Lucerne ID`, `Owner Lucerne ID`.
   - **Notes**: Linked to customers via `Owner Lucerne ID` and customer full names.

3. **`inventory.xlsx`**
   - **Target**: Shopmonkey Inventory & Parts Import
   - **Key Fields**: `Name*`, `Part # (optional)`, `SKU (optional)`, `Brand (optional)`, `Category (optional)`, `Cost (optional)`, `Retail (optional)`, `On Hand Quantity (optional)`, `Tax Exempt (optional)`.
   - **Notes**: Contains catalog items, stocked parts, and active inventory.

4. **`orders.xlsx`**
   - **Target**: Shopmonkey Historical Invoices / Work Orders Import
   - **Key Fields**: `Invoice Number`, `Customer Name`, `Vehicle`, `Created Date`, `Completed Date`, `Subtotal`, `Tax`, `Total`, `Balance Due`, `Payment Method`, `Status`, `Notes`.
   - **Notes**: Fully reconciled with customer and vehicle records.

5. **`lineitems.xlsx`**
   - **Target**: Shopmonkey Order Line Items Import
   - **Key Fields**: `Invoice Number`, `Item Type (Labor / Part / Sublet / Fee)`, `Description`, `Part Number`, `Quantity`, `Unit Cost`, `Unit Price`, `Total Price`, `Technician Note`.
   - **Notes**: Relates to `orders.xlsx` via `Invoice Number`.

## Instructions for Shop Owners

1. **Do not modify the file headers or sheet names** in `processed/`.
2. **Give these files (or this entire migration package) to the Shopmonkey migration team** (or your assigned Shopmonkey onboarding/migration specialist) for ingestion into your Shopmonkey shop account.
3. If the migration team has any technical questions regarding field mappings or historical key cross-references, refer them to the Lucerne documentation on GitHub or provide this guide.
4. Keep a copy of this archive in your secure backups for long-term historical record-keeping.
